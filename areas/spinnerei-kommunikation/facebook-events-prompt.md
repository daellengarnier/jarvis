# Prompt: Facebook-Events anlegen (Claude-App am Computer, Claude in Chrome)

Voraussetzungen: Session in der Claude-App am Computer mit dem Repo jarvis, Chrome offen, als Admin der Facebook-Seite der Spinnerei eingeloggt. Titelbilder liegen gesammelt im Drive-Ordner "Facebook Titelbilder Herbst 2026" (https://drive.google.com/drive/folders/1o8fsXO1HBjvxaN6SFtI74CC_ElNMN3sf): als ZIP herunterladen, entpacken, Pfad unten einsetzen, Facebook braucht sie als Datei.

Zum Einfügen:

```
Jarvis, leg mit Claude in Chrome die sechs Facebook-Events aus areas/spinnerei-kommunikation/facebook-events-herbst-2026.md auf der Facebook-Seite der Spinnerei an. Pro Event: Name, Datum und Zeit, Ort, Beschreibung, Ticket-Link genau aus der Datei übernehmen, Co-Gastgeber nur, wenn die Seite eindeutig gefunden wird, sonst weglassen und mir melden. Titelbilder liegen in <ORDNER>, fehlt eins, Event ohne Bild als Entwurf lassen. Alles als Entwurf speichern und vor jedem Veröffentlichen mit ⚠️ fragen. Am Ende die Facebook-Links in die jeweilige EVENT.md eintragen, Häkchen setzen, committen, pushen.
```
